# Список перед выпуском

Lattice — программа для Windows без сервера. «Выпуск» — это установщик на
странице GitHub Releases и файл `latest.yml`, по которому установленные копии
узнают о новой версии. Обновление идёт только вперёд, поэтому главное —
не выложить сломанную сборку.

## До сборки

- [ ] `npm run typecheck` — без ошибок
- [ ] `npm run i18n` — 0 пропущенных, лишних и сломанных строк во всех языках
- [ ] `npm test` — все тесты проходят
- [ ] Версия поднята в `package.json` и `package-lock.json`
- [ ] Файл состояния читается предыдущей версией: новые поля только добавляются,
      старые не меняют смысл (иначе нужен перенос в `store.ts` и тест на него)
- [ ] В README и в тексте выпуска есть предупреждение о личном ключе Nexus
- [ ] Нет известных ошибок, которые портят файлы в папке игры
- [ ] Новый разбор чужого формата (журнал, манифест, архив) проверен на образце из
      источника этого формата, а не написанном по памяти

## Сборка

- [ ] Сборка через короткий путь: `subst L: <папка проекта>`, затем `npm run dist`
      из `L:\` (длинные пути ломают упаковку)
- [ ] В `release/` появились три файла: `Lattice-Setup-<версия>.exe`,
      он же с `.blockmap`, и `latest.yml`
- [ ] Версия в `latest.yml` совпадает с версией в `package.json`
- [ ] Размер установщика не вырос без причины (0.3.4 — 127 МБ, 0.4.0 — 116 МБ)

## Проверка собранной программы

Проверяется именно то, что уйдёт людям, а не запуск из исходников.

- [ ] `release/win-unpacked/Lattice.exe --smoke --fixes --archives` завершается
      с кодом 0, в `smoke-trace.txt` нет ошибок
- [ ] Снимки в `smoke/` просмотрены глазами: все экраны, оба языка (русский и
      хотя бы один переведённый)
- [ ] В консоли окна нет ошибок

## Перед публикацией

- [ ] Поиск секретов в том, что попадёт в коммит: ключи, токены, почта,
      пути с именем пользователя
- [ ] В коммит не попали `node_modules`, `release`, `dist*`, `smoke`, `.scratch`,
      файлы состояния
- [ ] Автор коммита — учётная запись проекта, а не личная почта

## Публикация

- [ ] `git push`
- [ ] `gh release create v<версия>` с тремя файлами из `release/`
- [ ] Текст выпуска: что изменилось человеческим языком, что не проверено,
      предупреждение о ключе Nexus
- [ ] `subst L: /d`

## После публикации

- [ ] Страница выпуска открывается, все три файла скачиваются
- [ ] `latest.yml` на странице выпуска называет ту же версию и тот же файл
- [ ] Тесты на GitHub прошли на новом коммите
- [ ] Размер установщика записан в `docs/adr/0001-electron-or-rust.md`

## Когда отзывать выпуск

Отзывать — значит пометить выпуск как предварительный (`gh release edit
--prerelease`): установленные копии перестанут его предлагать, прошлый выпуск
снова станет последним. Тем, кто уже обновился, нужен исправляющий выпуск с
номером выше.

Отзывать сразу, если:

- программа не запускается или падает при открытии любого экрана;
- удаление мода оставляет его файлы в игре или трогает чужие;
- установка кладёт файлы за пределы папки игры и папок Lattice;
- файл состояния прежней версии не читается.

Исправлять следующим выпуском, не отзывая: ошибки перевода, вёрстки, ложные
предупреждения совместимости.
