# ADR-0001: остаёмся на Electron, а не переписываем на Rust (Tauri)

**Статус:** принято
**Дата:** 2026-11-12
**Кто решает:** владелец проекта (W1MR1)

## Контекст

К версии 0.4.0 рассматривался вопрос, переписывать ли Lattice с Electron на Rust
(Tauri): владелец разрешил это, «если требуется». Что было известно на момент
решения:

- Жалобы пользователей — функциональные: ложные ошибки совместимости (10 ошибок
  на рабочей сборке из 107 модов), моды, которые ложатся не туда, где игра их
  читает, непонятные значки, скачивание с Nexus без Premium. Ни одна из них не
  связана с Electron.
- Ядро (`electron/core`, около 9 тысяч строк TypeScript) не использует API
  Electron и покрыто тестами: 153 теста, включая сквозные с настоящими архивами.
- Установщик весит 127 МБ, из которых почти всё — сам Electron (Chromium).
- Разработчик один. На машине сборки нет Rust и инструментов сборки MSVC.
- Обновления идут через `electron-updater` и GitHub Releases; установщик NSIS
  с шестью языками и шагом удаления настроен и проверен.

## Решение

Остаться на Electron. Вес установщика уменьшить в рамках Electron (убрать
неиспользуемые языковые пакеты Chromium и сборки 7-Zip для других платформ).
К вопросу вернуться, когда появится хотя бы одно из условий ниже.

## Рассмотренные варианты

### Вариант A: остаться на Electron

| Измерение | Оценка |
|-----------|--------|
| Сложность | Низкая: ничего не меняется |
| Цена | Нулевая; время уходит на ошибки, о которых пишут пользователи |
| Размер и память | Установщик около 115 МБ, 250–350 МБ памяти |
| Знакомство с технологией | Полное: весь код и все тесты уже на TypeScript |

**За:** проверенное ядро остаётся как есть; обновления, установщик и языки уже
работают; всё время идёт на качество.
**Против:** большой установщик; заметный расход памяти.

### Вариант B: Tauri, ядро переписать на Rust

| Измерение | Оценка |
|-----------|--------|
| Сложность | Высокая: переписать решатель, развёртывание, шесть источников, FOMOD, чтение jar, перенос из других менеджеров, загрузчик |
| Цена | Недели работы и новая волна ошибок в коде, который сейчас проверен |
| Размер и память | Установщик 10–15 МБ, память 80–150 МБ |
| Знакомство с технологией | Нужны Rust, MSVC, новый механизм обновлений и подпись для него |

**За:** маленький установщик, меньше памяти, быстрый запуск.
**Против:** 153 теста придётся писать заново; интерфейс зависит от версии
WebView2 на машине пользователя; обновления Tauri требуют ключей подписи;
ни одна текущая жалоба этим не решается.

### Вариант C: Tauri, ядро оставить на TypeScript (отдельный процесс Node)

| Измерение | Оценка |
|-----------|--------|
| Сложность | Средняя: новый мост между интерфейсом и ядром, упаковка Node рядом |
| Цена | Дни-недели; выигрыш в размере съедается вложенным Node (около 40 МБ) |
| Размер и память | Установщик около 50 МБ |
| Знакомство с технологией | Частичное |

**За:** ядро и тесты сохраняются.
**Против:** два процесса и два способа упаковки вместо одного; выигрыш
половинчатый.

## Сравнение

Главный довод в пользу Rust — размер и память. Главный довод против — риск:
переписывание заменяет проверенный код новым именно там, где ошибка стоит
дороже всего (файлы в папке игры). При одном разработчике это время, отнятое у
ошибок, из-за которых у людей не работают моды. Вариант C выглядит компромиссом,
но добавляет сложность, не давая основного выигрыша.

## Последствия

- Проще: все силы — на корректность установки и диагностику.
- Сложнее: установщик остаётся большим; в 0.4.0 он легче только на объём
  ненужных языковых пакетов и чужих сборок 7-Zip.
- Вернуться к вопросу, если: появится второй разработчик с опытом Rust;
  размер установщика станет главной жалобой; Electron перестанет поддерживать
  нужную версию Windows.

## Что сделать

1. [x] Убрать из установщика языковые пакеты Chromium, кроме шести языков Lattice.
2. [x] Не класть в установщик 7-Zip для Linux, macOS, x86 и ARM.
3. [x] Держать ядро свободным от API Electron (`electron/core` импортирует
   только Node): если переезд когда-нибудь понадобится, интерфейс и ядро можно
   будет переносить по отдельности.
4. [x] Измерить размер установщика 0.4.0: **115,7 МБ** против 127,0 МБ у 0.3.4
   (минус 11,3 МБ, около 9 %). Остальное — сам Electron; дальше в рамках
   Electron уменьшать почти нечего.
