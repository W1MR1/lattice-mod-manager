# Дизайн-система Lattice

Основа — «чертёжный стол»: тёплый графит, тонкие линии вместо теней, один
акцентный цвет (ирис) и цвета статусов, которые всегда что-то значат.
Сборка модов показана как решётка связей. Связи (требует / нужен для /
конфликтует) видны в каждой строке, а не спрятаны в отдельном окне.

Чем Lattice отличается от Vortex:

| | Vortex | Lattice |
|---|---|---|
| Навигация | текстовый сайдбар со всеми разделами | узкая рельса игр + вкладки рабочего пространства |
| Палитра | тёмно-синий bootstrap, оранжевые акценты | тёплый графит, ирис-акцент, статусные цвета |
| Шрифты | Montserrat / Roboto / Inter | Manrope (интерфейс) + JetBrains Mono (версии, хэши, размеры) |
| Глубина | тени, плашки | линии 1px, слои фона, без теней кроме всплывающих |
| Ключевой визуал | список модов | индикатор «здоровья» сборки и граф связей |

## Токены

Все значения — CSS-переменные в `src/styles/tokens.css`. В компонентах нет
захардкоженных цветов, отступов и размеров шрифта.

### Цвет

| Токен | Тёмная | Светлая | Назначение |
|---|---|---|---|
| `--bg-0` | `#0e0f10` | `#f4f2ee` | фон окна, рельса |
| `--bg-1` | `#151618` | `#fbfaf7` | рабочая область |
| `--bg-2` | `#1c1d20` | `#ffffff` | карточки, инспектор |
| `--bg-3` | `#25262a` | `#efece6` | наведение, поля ввода |
| `--line` | `#2a2b30` | `#e3dfd6` | разделители, рамки |
| `--line-strong` | `#3a3b42` | `#cfc9bd` | рамки активных полей |
| `--text-1` | `#eceae6` | `#1b1a18` | основной текст |
| `--text-2` | `#a9a6a0` | `#5d5952` | вторичный текст |
| `--text-3` | `#6f6c67` | `#8f8a80` | подписи, плейсхолдеры |
| `--accent` | `#8b7cf6` | `#5b4bd8` | основное действие, фокус, выбор |
| `--accent-soft` | `rgb(139 124 246 / .14)` | `rgb(91 75 216 / .10)` | подложка выбранного |
| `--ok` | `#4cc38a` | `#1f8a5b` | совместимо, готово |
| `--warn` | `#e6a23c` | `#b26b00` | предупреждение, рекомендация |
| `--err` | `#ef5f5f` | `#c2304f` | конфликт, отсутствует зависимость |
| `--info` | `#4fb3d9` | `#1d7fa6` | информация, загрузка |

Статусные цвета проверены валидатором палитр (навык dataviz). Контраст с
фоном не ниже 3:1 в обеих темах. Различимость при обычном зрении в тёмной
теме не ниже 15. Пара «ошибка ↔ предупреждение» в светлой теме при
дейтеранопии различима только на уровне ΔE 6.8, и это законно только с
дополнительным кодированием. Поэтому **статус всегда дублируется иконкой и
словом** (StatusChip, глиф в узлах графа) и никогда не передаётся одним цветом.

### Типографика

| Токен | Размер / межстрочный | Вес | Где |
|---|---|---|---|
| `--fs-xs` | 11 / 16 | 600, прописные, трекинг .06em | метки секций |
| `--fs-sm` | 12 / 18 | 500 | чипы, вторичный текст |
| `--fs-md` | 13 / 20 | 500 | основной текст интерфейса |
| `--fs-lg` | 15 / 22 | 600 | заголовки карточек |
| `--fs-xl` | 20 / 28 | 700 | заголовок экрана |
| `--fs-2xl` | 28 / 34 | 800 | цифры-показатели (здоровье, скорость) |

`--font-ui: Manrope`, `--font-mono: JetBrains Mono` (цифры с
`font-variant-numeric: tabular-nums`). Шрифты лежат локально
(`@fontsource`), сеть для них не нужна.

### Отступы, радиусы, движение

- Шаг 4px: `--s-1` 4, `--s-2` 8, `--s-3` 12, `--s-4` 16, `--s-5` 20, `--s-6` 24, `--s-8` 32, `--s-10` 40.
- Радиусы: `--r-sm` 6 (контролы), `--r-md` 10 (карточки), `--r-lg` 14 (модальные окна), `--r-pill` 999.
- Тень только у всплывающих слоёв: `--shadow-pop`.
- Движение: `--dur-fast` 120ms, `--dur` 200ms, `--ease` `cubic-bezier(.2,.7,.2,1)`. При `prefers-reduced-motion` анимации отключаются.

## Компоненты

### Button
Варианты: `primary` (ирис, одно на экран), `secondary` (рамка), `ghost`
(без рамки, для тулбаров), `danger`. Размеры `sm` 28px, `md` 32px.
Состояния: hover — фон `--bg-3` / осветление акцента; active — сдвиг на 1px;
disabled — 45% непрозрачности, без курсора; loading — спиннер вместо иконки,
ширина сохраняется. Доступность: настоящий `<button>`, видимое кольцо
фокуса `--accent` 2px.

### StatusChip (чип совместимости)
`ok` · `warn` · `err` · `info` · `muted`. Иконка + короткое слово
(«Совместим», «Нет зависимости», «Конфликт»). Высота 22px, `--fs-sm`.
Для экранного диктора: `aria-label` с полным описанием проблемы.

### LinkCounter (связи в строке мода)
Две метки: `↳ требует N` и `↑ нужен для M`. При наведении — список
связанных модов. Если хоть одна связь сломана, метка становится `--err`.
Это главный «Lattice-элемент»: связи видны без перехода в граф.

### HealthRing
Кольцо 0–100 по оценке совместимости сборки и счётчики ошибок и
предупреждений. Цвет по порогу: ≥90 `--ok`, ≥60 `--warn`, иначе `--err`.
Клик открывает экран «Совместимость».

### ModTable
Строки 44px, колонки: переключатель · иконка+название+автор · версия (mono)
· источник · связи (LinkCounter) · статус (StatusChip) · меню.
Выбранная строка: фон `--accent-soft` и полоса 2px слева. Клавиатура:
↑/↓ по строкам, Space — вкл/выкл, Enter — открыть инспектор, Delete — удалить
(с проверкой зависимых).

### Inspector
Правая панель 380px: заголовок, версии, «Требует» и «Нужен для» списками,
правила порядка загрузки, файлы, действия. Закрывается Esc.

### SegmentBar (сегментный прогресс загрузки)
Полоса делится на сегменты по реальным диапазонам байтов. Каждый
сегмент заполняется отдельно, активные мерцают. Под полосой — скорость
(mono, tabular), число потоков, ETA. Показывает, что загрузка идёт
несколькими потоками и ничем не ограничена.

### PlanSheet (план установки)
Модальная панель перед любым изменением сборки: что будет установлено,
обновлено, оставлено. Отдельно перечислены зависимости, которые подтянутся,
и найденные проблемы с кнопками-исправлениями. Кнопка «Применить» недоступна,
пока есть ошибки (их можно явно проигнорировать флажком).

### DependencyGraph
SVG-граф по слоям (зависимости слева, зависимые справа). Узлы — плашки
со статусной точкой, рёбра — кривые: сплошная «требует», пунктир
«рекомендует», красная «конфликтует». Наведение подсвечивает соседей,
клик выбирает мод.

### FomodWizard (мастер установщика FOMOD)
Модальное окно поверх плана установки: шаг за шагом, у каждой группы своя
подсказка («выберите один», «любые», «ставятся все»). Для групп «один из»
используются радио, для остальных флажки. Вариант со статусом «Обязательно»
отмечен и заблокирован, «Недоступно» — приглушён. Шаги показываются и
скрываются по флагам прямо во время выбора, по той же логике, по которой
главный процесс потом раскладывает файлы. Внизу счётчик «Будет установлено»
или первая ошибка выбора. Esc закрывает только верхнее окно.

### Toast с откатом
Уведомление об успешной установке несёт кнопку «Откатить», которая
возвращает снимок, сделанный перед изменением. Такое уведомление держится
10 секунд, обычное — 4,5.

## Паттерны

- **Рабочее пространство игры**: рельса игр (64px) → шапка (игра, профиль,
  здоровье, поиск) → вкладки → контент + инспектор → строка состояния
  (суммарная скорость загрузок, статус развёртывания).
- **Безопасные изменения**: любое изменение идёт через PlanSheet → снимок
  профиля → применение. Откат делается из «Снимков» одним действием.
- **Пустые состояния**: одна фраза о том, что здесь будет, и одно действие.
- **Ошибки**: что случилось и что сделать, без кодов на первом плане.
