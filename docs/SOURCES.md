# Откуда Lattice берёт моды — и откуда не берёт

Короткий ответ: Lattice подключается только к сайтам, куда мод выложил **сам
автор**, у которых есть **официальный способ** для программ получать файлы, и
где файл можно **проверить**. Сайтов-перезаливов, «зеркал» и торрентов в
Lattice нет и не будет. Ниже — почему, по каждому источнику.

Проверено в ноябре 2026 года запросами к самим сервисам и по их документации.

## Что подключено

| Источник | Для каких игр | Как Lattice с ним работает | Что проверяется |
|----------|---------------|----------------------------|-----------------|
| **Modrinth** | Minecraft | Открытый API, ключ не нужен. Моды, сборки (`.mrpack`), ресурспаки, шейдеры | sha512 каждого файла; версия игры и загрузчик — ещё и по самому jar |
| **CurseForge** | Minecraft и другие | Официальный Core API. Нужен ключ, который CurseForge выдаёт по заявке | sha1 / md5; автор может запретить скачивание сторонним программам — тогда Lattice откроет страницу мода |
| **Thunderstore** | 266 игр на BepInEx: Lethal Company, R.E.P.O., PEAK, Valheim, Risk of Rain 2, Among Us и другие | Открытый индекс каждого сообщества. Список игр, их папок и правил установки взят из [официального реестра Thunderstore](https://thunderstore.io/api/experimental/schema/dev/latest/) — того же, по которому работает r2modman | размер файла и HTTPS (хэшей Thunderstore не отдаёт) |
| **Nexus Mods** | Skyrim SE, Fallout 4, Cyberpunk 2077, Stardew Valley, Valheim, Lethal Company | Официальный API: поиск, файлы, требования, сборки (Collections). Скачивание — по правилам Nexus, см. ниже | размер и md5 там, где Nexus их отдаёт |
| **GitHub Releases** | Все игры | Официальный API. Основы модовых сцен лежат именно здесь: RED4ext, Cyber Engine Tweaks, redscript, ArchiveXL, SMAPI | только размер и HTTPS — поэтому на вкладке стоит предупреждение, см. ниже |
| **GameBanana** | Игры, для которых там есть раздел | Официальный API | md5 |
| **Файл с диска** | Все игры | Перетащите архив или папку в окно | раскладка архива и наличие нужных основ |

Общее для всех: только HTTPS и только адреса из списка доверенных; имена файлов
из архива не могут вывести за пределы папок Lattice; об исполняемых файлах в
архиве Lattice предупреждает.

### Nexus Mods без Premium и без ключа

Nexus отдаёт файлы бесплатным аккаунтам только через собственный сайт: человек
должен сам нажать кнопку скачивания. Lattice это правило не обходит, а берёт на
себя всё остальное:

1. План установки показывает, каких файлов с Nexus не хватает, и открывает
   нужную страницу — сразу на нужном файле.
2. Вы нажимаете «Slow download» на сайте. Браузер сохраняет архив в папку
   загрузок.
3. Lattice сам находит этот файл, сверяет размер с тем, что называет Nexus,
   забирает его и продолжает установку. Если включены ссылки `nxm://`, достаточно
   кнопки «Mod Manager Download».

Так работают и отдельные моды, и сборки на сотню модов: список ожидаемых файлов
отмечается по мере того, как они появляются. Ограничение скорости для
бесплатных аккаунтов — на стороне Nexus, и Lattice его не трогает.

### GitHub: источник нужный, но не каталог

На GitHub нет модерации модов: репозиторий может создать кто угодно, а «звёзды»
накручиваются. Это не теория. В 2025 году Check Point описала сеть из тысяч
поддельных аккаунтов GitHub, которая раздавала вредоносные программы под видом
модов и читов для Minecraft. В 2026 году McAfee сообщила о более чем 116 тысячах
заражённых игроков: им подсовывали «моды» через поддельные страницы, поднятые в
поиске.

Поэтому в Lattice:

- для каждой игры сначала показаны известные проекты (для Cyberpunk 2077 —
  RED4ext, Cyber Engine Tweaks, redscript, ArchiveXL, TweakXL, Codeware);
- поиск ограничен словами игры и отсеивает сборки под другие системы;
- на вкладке GitHub стоит предупреждение: ставьте то, на что ссылается сам
  автор мода или его страница на Modrinth, Nexus, Thunderstore.

## Что рассматривалось и не подключено

| Сайт | Почему нет |
|------|------------|
| **Торрент-трекеры и раздачи «сборок модов»** | Мод на трекер выкладывает не автор. Нельзя узнать, тот ли это файл: нет ни подписи, ни хэша от автора, ни истории версий. Обновлений нет. Это самый простой способ получить вместе с модом чужую программу — и самый частый, судя по отчётам выше. Вдобавок перезалив чужого мода без разрешения нарушает и права автора, и правила площадок, с которых он взят |
| **«Зеркала» Nexus и сайты, которые копируют моды к себе** | То же самое: файлы взяты без разрешения авторов ([правила Nexus](https://help.nexusmods.com/article/28-file-submission-guidelines) прямо запрещают раздавать чужие файлы без согласия владельца), проверить подлинность нечем. Заменой Premium они не являются: Premium — это скорость и удобство, а не доступ; все файлы Nexus и так доступны бесплатно, см. «Nexus Mods без Premium» выше |
| **Сайты-перезаливы модов Minecraft** (9minecraft и подобные) | Собирают чужие моды, зарабатывают на рекламе, версии устаревшие или подменённые. Всё, что там есть, лежит на Modrinth и CurseForge в оригинале |
| **mod.io** | API есть, но ключ выдаётся на каждую игру, а игр, которые поддерживает Lattice, там почти нет: mod.io встроен в сами игры, и моды оттуда ставятся из меню игры |
| **Steam Workshop** | Файлы отдаёт только сам Steam владельцу игры; сторонней программе — только через `steamcmd` с входом в аккаунт. Моды Workshop ставит сам Steam, второй менеджер тут лишний |
| **ModDB, Bethesda.net (Creations), LoversLab, AFK Mods** | Нет открытого API для программ. Разбирать страницы сайта — ненадёжно и против их правил. Файл оттуда можно скачать самому и перетащить в Lattice |

## Если нужного мода нет ни в одном источнике

Скачайте его там, где его выложил автор, и перетащите архив в окно Lattice.
Lattice разберёт архив так же, как скачанный из каталога: спросит про варианты,
разложит файлы туда, где их читает игра, проверит, установлены ли нужные основы,
и после запуска игры покажет по её журналу, загрузился ли мод.
