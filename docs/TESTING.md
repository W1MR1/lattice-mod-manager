# Как проверяется Lattice

Lattice кладёт файлы в папку игры. Ошибка здесь стоит дорого: сломанная игра,
потерянные сохранения, часы на переустановку. Поэтому главный вес тестов — там,
где программа трогает диск и где она решает, что ставить.

## Что запускать

```bash
npm run typecheck   # типы
npm run i18n        # переводы: ни одной пропущенной строки в пяти языках
npm test            # 153 теста, около 3 секунд
npm run smoke       # собранное окно: все экраны по очереди, снимки в smoke/
```

Первые три команды выполняются на GitHub при каждом изменении
(`.github/workflows/test.yml`). Четвёртая — вручную перед выпуском: ей нужен
экран.

## Пирамида

```
        /  прогон окна  \        1 сценарий, 8 экранов, снимки
       /   сквозные тесты  \     ~60: настоящие архивы, настоящая файловая система
      /    тесты модулей     \   ~85: решатель, совместимость, раскладка, разбор журналов
```

Тестов интерфейса (нажатия, формы) нет — это главный пробел, см. ниже.

## Что покрыто и чем

| Область | Файлы тестов | Вид | Что именно проверяется |
|---------|--------------|-----|------------------------|
| Подбор версий и зависимостей | `resolver`, `v032` | модуль | версия под игру и загрузчик, обязательные зависимости, конфликты, зависимость, которой нет для загрузчика, не блокирует план |
| Совместимость | `compat`, `compat-real` | модуль + образец | настоящая сборка из 107 модов (`tests/data/zombie-pack.json`) даёт 0 ложных ошибок; те же моды на чужом загрузчике дают ошибки |
| Раскладка архива | `layout` | модуль | обёртки, файлы россыпью, варианты «на выбор», Cyberpunk, Skyrim/Fallout, Stardew, BepInEx |
| Установка | `installer`, `install-layout`, `fomod`, `archives` | сквозной | zip/7z/rar распаковываются во временную папку, проверяется каждый путь; вопросы FOMOD, выбор варианта |
| Развёртывание и удаление | `removal`, `v030`, `v031` | сквозной | после удаления мода в папке игры не остаётся ни одного его файла; чужие файлы не тронуты; снимки возвращают прежнее состояние |
| Перенос из Vortex, MO2, r2modman | `v031`, `v032`, `v033` | сквозной | остатки чужого менеджера, карантин, собственные файлы Lattice не принимаются за чужие |
| Игры из реестра Thunderstore | `thunderstore-games` | модуль + сквозной | каждая из 262 игр описана полностью; игра находится только в своей папке Steam; загрузчик сообщества подставляется вместо чужого; чужие менеджеры модов не предлагаются как моды |
| Загрузки | `downloader`, `nexus-assist`, `nexus-sso` | сквозной (локальный сервер) | докачка, проверка суммы, подхват файла из папки загрузок, отказ принять файл другого размера |
| Журналы игр | `gamelog` | модуль на образцах | Fabric, Forge, BepInEx, SMAPI, RED4ext, CET, redscript, SKSE: кто загрузился, кто упал |
| Порядок плагинов | `plugins` | модуль | `plugins.txt`, мастер-файлы первыми |
| Безопасность | `safety` | сквозной | имя файла с `../` не выходит из папки Lattice; в отчёте о проблеме нет домашней папки, ключей и подписанных ссылок |
| Переводы | `i18n` | модуль | каждая строка интерфейса есть во всех языках, подстановки `{0}` совпадают |

## Правила, по которым пишутся тесты

1. **Каждая найденная ошибка сначала становится тестом.** Десять ложных ошибок
   на сборке пользователя — это теперь `compat-real.test.ts` с настоящими
   данными той сборки.
2. **Диск — настоящий.** Тесты установки и удаления работают во временной папке
   с настоящими архивами, а не с подменой файловой системы: ошибки здесь живут
   как раз в мелочах (регистр букв, длинные пути, занятые файлы).
3. **Сеть — никогда.** Источники подменяются; загрузчик проверяется на
   локальном сервере. Тесты не зависят от того, жив ли Modrinth.
4. **Ядро не знает про Electron.** `electron/core` импортирует только Node,
   поэтому всё, кроме окна, проверяется без запуска программы.

## Чего тесты не покрывают

Это честный список, а не оговорка.

| Пробел | Чем опасен | Что вместо этого сейчас | План |
|--------|------------|-------------------------|------|
| Нет тестов интерфейса | кнопка может перестать работать, и тесты этого не увидят | прогон окна со снимками всех экранов; ручная проверка перед выпуском | начать с окна установки: вопросы FOMOD, выбор варианта, список Nexus |
| Раскладки и журналы проверены на образцах | настоящий мод может быть упакован так, как образцы не предусмотрели | неизвестная раскладка не ставится молча: Lattice спрашивает, куда класть; журнал, который не разобран, просто не даёт выводов | каждый присланный «отчёт о проблеме» превращать в образец |
| Игры не запускаются | «мод установлен правильно» не значит «мод работает в игре» | после запуска игры Lattice читает её журнал и говорит, какие моды загрузились | — |
| Из 266 игр на BepInEx вживую проверены восемь | у какой-то игры пакет загрузчика может быть устроен иначе | правила взяты из реестра Thunderstore, игры с особыми правилами в список не берутся; прогон `--ts-games=…` проверяет любую игру за минуту | прогонять новые популярные игры перед выпуском |
| Установщик и удаление программы | шаг удаления NSIS не прогоняется автоматически | ручная проверка | — |
| Только Windows x64 | — | — | другие системы не заявлены |

## Перед выпуском

Полный список — в [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md). Коротко: типы,
переводы, тесты, сборка, прогон **собранной** программы (не той, что из
исходников), проверка на секреты.
