# Rehearsal: lattice-install

Демо-ролик для лендинга или README: анимированная иллюстрация окна Lattice,
собранная на наборе Stageshow (`demo/kit`, MIT). Это не само приложение:
настоящий интерфейс живёт в `src/`.

**Gold:** `dark-hero`. Взято без изменений: сцена 760×440, раскладка «корнер-блид»
(окно отступает сверху и слева, уходит за правый и нижний край), новые строки
открываются сверху через `Collapse` и несут список вниз, статус меняется на своей
же плашке. Изменено: оформление по токенам Lattice (графит, ирис `#8b7cf6`,
Manrope, JetBrains Mono для версий), добавлены спутник-карточка над рельсой игр и
тост. Для телефона взята раскладка из `stacked-cards`: карточка плана и панель
списка одной ширины, 12 px между ними, панель уходит за низ.

**Beats** (широкая версия, цикл ≈ 18,6 с):
1. Курсор жмёт «Установить» на карточке Iris Shaders.
2. Та же карточка раскрывается в план: Iris Shaders — по запросу, Sodium — нужен
   для Iris, «Связи сходятся».
3. «Применить»: карточка становится «В профиле», сверху открываются две строки,
   у каждой своя сегментная полоса загрузки (1 и 2 соединения, как в реальной
   загрузке этих файлов с Modrinth).
4. Финал: обе строки «Совместим», счётчик «модов» катится 4 → 6, тост
   «Установлено 2 мода» с кнопкой «Откатить». Держится 2,3 с.
5. Курсор жмёт «Откатить»: строки уходят одним движением, карточка возвращается
   к «Установить». У сброса цикла есть видимая причина: это настоящая функция
   Lattice (откат к автоматическому снимку из тоста).

На телефоне план открыт с первого кадра, поэтому первого нажатия нет.

**Captured:** ширина 1280 (широкая версия) и 390 (компактная, 358 px), тёмная тема
продукта, лист всех состояний (`--states`), кадр reduced motion (`docs/demo-poster.png`,
`docs/demo-poster-phone.png`), отдельно прогон из проекта (`npm run demo`).

**Film** (`film.mjs --gate`):
- Широкая версия: `rehearsal passed` (в плейграунде и в проекте).
- Телефон: одна строка `uneven gutters` у верхней карточки стопки. Её же
  получает «золотой» `stacked-cards` на 390 px: эвристика оценивает верхнюю
  карточку стопки отдельно. Оставлено намеренно.
- `lopsided` у индикатора здоровья: кольцо внутри «пилюли» отступает на 3 px со
  всех сторон, текст справа — на 12 px, как аватар в чипе. Оставлено.
- `touching` «Сборка цела / модов»: строки цифр `Count` по высоте выходят за
  свою строку. Сама строка обрезана (`overflow: hidden`), визуально наложения нет.
- `lands on a transform` у строки Sodium и `hard edge` у галочки внутри `Collapse`:
  слой на строки внутри открывающегося блока даёт одно, без слоя — другое.
  Оставлен вариант без слоя: строки угасают вместе с блоком.
- Исправлено по ходу: отступ карточки и общий отступ 40 px, плитка рельсы под
  краем карточки (шаг рельсы подобран так, что края карточки во всех трёх
  состояниях попадают в промежутки), пустая полоса заголовка окна (заголовок
  перенесён в полосу), иконки 11 px на полупикселях (стали 12 px), сжатая
  галочка в бейдже (`flex: none`, чётная ширина 96 px), тост в нижнем отступе,
  кнопка, «приземлявшаяся» на трансформации (нажатие теперь цветом), панель
  на телефоне вместо окна выше чем шире.

**Review:** независимый ревьюер (отдельный агент по `references/review.md`) не
запускался. Ревью по тому же чек-листу сделано самим автором по кадрам; отданная
на исправление находка была одна: полоска плитки рельсы над карточкой.

**Assumptions:** иконки модов показаны нейтральными плитками-заглушками (своих
ассетов у Lattice нет, а «буква в квадрате» запрещена правилами); рамка окна —
стандартная рамка набора Stageshow.

**Unresolved:** нет.

**Not checked:** светлая тема (у Lattice по умолчанию тёмная, ролик рассчитан на
тёмную страницу); поведение на хостовой странице шире 1600 px; проигрывание при
ускоренном `speed`.
